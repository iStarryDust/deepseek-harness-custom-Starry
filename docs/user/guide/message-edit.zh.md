# 编辑消息并重新生成

[English](message-edit.md) | 中文

对话中的每条用户消息在复制、分支旁边都有一个**编辑**入口。编辑会改写提示词并从该消息处重新生成对话；原消息之后的轮次不会被保留。

## 编辑已发送的消息

1. 悬停一条已发送的用户消息，选择铅笔图标。Agent 仍在执行当前轮次时不可编辑。
2. 内联编辑器打开并聚焦原文。下方一条图片栏显示这条消息携带的图片。
3. 修改文本。点击缩略图上的 **×** 移除图片；通过 **＋** 或把文件拖到图片栏上新增图片（支持 png、jpeg、webp、gif）。
4. 选择**重新生成**，或按 <kbd>Ctrl</kbd>+<kbd>Enter</kbd>（macOS 为 <kbd>Cmd</kbd>+<kbd>Enter</kbd>）。按 <kbd>Esc</kbd> 或选择**取消**放弃本次编辑。

## 重发时会发生什么

对话会**从被编辑的消息处分叉（fork）**。宿主创建一个分支会话：重放被编辑消息之前的所有轮次，用编辑后的提示词替代原消息发送，然后打开分支。被编辑消息之后的轮次不会延续。

- 原会话保留在侧边栏；分支作为一个新会话出现。两者都不会被自动删除——分支不再需要时，请手动清理会话列表。
- 分支会继承原会话使用的模型，因此带图片重发不会回退到不支持视觉的默认模型。
- 原消息保留的图片原样复用；新增图片走与输入框相同的上传管线。

## 重发失败时

视图停留在当前会话，编辑器带着你的文本和失败提示重新打开。残留的空分支会被自动删除，失败的编辑不会留下多余会话。

## 限制

- 只能编辑用户消息；助手回复只提供复制和分支。
- 原会话保留完整消息记录——append-only 记录不会被改写。
