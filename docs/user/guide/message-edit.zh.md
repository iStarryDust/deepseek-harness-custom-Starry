# 编辑消息并重新生成

[English](message-edit.md) | 中文

对话中的每条用户消息在复制、分支旁都有一个**编辑**入口。编辑会改写提示词并从该消息处重新生成对话；原消息之后的轮次不会被保留。

## 编辑已发送的消息

1. 悬停一条已发送的用户消息，选择铅笔图标。Agent 正在执行轮次时不可编辑。
2. 内联编辑器打开并聚焦原文，下方的图片栏显示这条消息携带的图片。
3. 修改文本；点击缩略图上的 **×** 移除图片，通过 **＋** 或将文件拖入图片栏新增图片（支持 png、jpeg、webp、gif）。
4. 选择**重新生成**，或按 <kbd>Ctrl</kbd>+<kbd>Enter</kbd>（macOS 为 <kbd>Cmd</kbd>+<kbd>Enter</kbd>）；按 <kbd>Esc</kbd> 或选择**取消**放弃本次编辑。

## 重发时会发生什么

对话会**从被编辑的消息处分叉（fork）**：宿主创建一个分支会话，重放被编辑消息之前的所有轮次，用编辑后的提示词替代原消息发送，然后打开分支。被编辑消息之后的轮次不会延续。

- 原会话保留在侧边栏，分支作为一个新会话出现；两者都不会被自动删除，不再需要的分支会话请手动删除。
- 分支继承原会话的模型，因此带图片重发不会回退到不支持视觉的默认模型。
- 原消息保留的图片原样复用；新增图片走与输入框相同的上传管线。

## 重发失败时

视图停留在当前会话，编辑器带着已输入的文本和失败提示重新打开；残留的空分支会被自动删除。

## 限制

- 只能编辑用户消息；助手回复仅提供复制和分支。
- Agent 正在执行轮次时不可编辑；上下文压缩后，所在轮次已不在当前窗口的用户消息也不可编辑。
- 原会话保留完整消息记录，append-only 记录不会被改写。
